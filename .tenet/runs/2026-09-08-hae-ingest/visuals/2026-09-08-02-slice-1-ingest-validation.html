Phone setup — 3 HAE REST automations → dev machine (LAN)

Health Auto Export → Automations → New → REST API

Automation: metrics-all
  URL:        http://<dev-machine-LAN-IP>:8000/api/ingest
  Header:     X-Ingest-Token: <token from .env>
  Format:     JSON · v2 · Summarize ON · hours
  Range:      Standard · Batch ON · hourly

Automation: metrics-hr-steps
  (same, but only Heart Rate + Step Count, minutes)

Automation: workouts
  (Include Workout Metrics ON, Route Data ON, daily)
